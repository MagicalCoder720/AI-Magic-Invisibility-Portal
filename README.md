# AI-Magic-Invisibility-Portal
This is a Magical Invisibility Portal made by using Computer Vision

🌟 AI Magic Invisibility Portal — Dual Hand Edition 🌟
I recently built a creative computer vision project that turns your webcam into a magical invisibility portal controlled entirely by your hands!

🔹 How it works:
Both hands create their own portals, anchored at each index fingertip.
The thumb–index pinch distance controls each portal’s size in real time.
Portals can take on different shapes: circle → hexagon → star.
Inside each portal, you can apply 7 unique live filters:
1.Reveal – classic invisibility (shows captured background)
2.Swirl – localized warp distortion
3.Thermal – heat‑map false color
4.Pixelate – retro chunky pixel blocks
5.Edge – neon edge outlines
6.Mirror – horizontally mirrored live feed
7.Drain – grayscale desaturation

🔹 Controls:
B → capture/recapture static background
S → cycle portal shape
1–7 → switch filters
Q / Esc → quit
🔹 Tech Stack:
Python
OpenCV
MediaPipe HandLandmarker
NumPy
💡 This project combines gesture recognition, image processing, and interactive design to create a playful illusion of stepping into another dimension. It’s a fun demonstration of how computer vision can be used for creative, magical experiences beyond traditional applications.
